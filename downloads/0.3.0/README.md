# 0.3.0 — мониторинг устройства

В настройках добавлен отдельный URL сводки Pi (/status). Источник доступен через
Tailscale, адрес вводится пользователем и не включён в публичный APK.
Показатели: CPU, температура, память, swap, диски, uptime, активные контейнеры,
контролируемые сервисы и попытки восстановления. Устаревшие данные отмечаются.
Добавлены уведомления по серверным предупреждениям и потере/восстановлению связи.

Проверены сборка и Android Lint (41097387153), SHA256 APK, серверный JSON-контракт,
актуальность и диапазоны показателей, read-only API и VPN bind.
На физическом телефоне версия пока не протестирована.

Это тестовый debug APK. При конфликте подписей сохраните адреса и переустановите
приложение; удаление стирает настройки. После установки разрешите уведомления.
Источник в server/README.md. MQTT пока только состояние контейнера, не протокол.
