Первая тестовая Android-версия Pi Pocket Monitor (Android 8+).

- Опрос настроенных HTTP(S) адресов при разблокированном экране.
- Интервал 2–30 минут, уведомление после трёх ошибок и при восстановлении.
- Локальный журнал, управление запуском и остановкой.
- Нет встроенных адресов, аккаунтов или токенов.

Сборка debug для ручного тестирования. На физическом телефоне пока не проверена.
После установки нужно ввести endpoint и разрешить уведомления/фоновую работу.
После перезагрузки телефона мониторинг включается вручную. Это не круглосуточная внешняя проверка.
Адреса проверяются независимо: не добавляйте домашний IP для постоянного контроля вне домашней сети.
Обновления debug-сборки с другим ключом могут потребовать переустановки и повторного ввода настроек.
