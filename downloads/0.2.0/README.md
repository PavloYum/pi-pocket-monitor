# 0.2.0 — обновлённый интерфейс

- Обзор с общим статусом и карточками сервисов.
- Отдельные экраны настроек и истории проблем/восстановлений.
- Светлая и тёмная палитра по настройке системы.
- Обновление статусов на экране, время проверки и признак устаревших данных.
- Отступы для системных панелей Android.

Сборка и Android Lint: успешно (GitHub Actions 41018101353).
SHA256 проверен после скачивания. Внешний вид и работа на физическом телефоне
для этой версии пока не проверены. Общая диагностика Pi пока не подключена.

Это debug APK. Если установка поверх 0.1.0 отклонена из-за подписи, сохраните
адреса отдельно, удалите предыдущую версию и установите эту. Настройки приложения
при удалении теряются. После установки разрешите уведомления и включите мониторинг.
