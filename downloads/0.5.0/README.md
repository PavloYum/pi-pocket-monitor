# 0.5.0 — история и диагностика, без резервных копий

- Графики за час, сутки, неделю; локальная история до 7 дней.
- Скорости сети и записи дисков, CPU/RAM/температура/свободное место.
- Проверка обязательных Docker-сетей, PostgreSQL SELECT 1, камера video/audio.
- Текущее/историческое низкое напряжение и троттлинг, SMART SSD, USB/I/O ошибки.
- Инциденты сервера с открытием и завершением, без дублирования одной проблемы.
- Режим обслуживания с ограничением времени (команда на Pi в server/README.md).
- Постоянная release-подпись; секреты вне Git.

Без резервного копирования данных. История начинается после обновления.
MQTT CONNECT проверяется, публикация требует отдельного диагностического аккаунта.
Функциональная обработка сообщений ботами без heartbeat не подтверждается.
Камера кратковременно активируется проверкой ffprobe, записи нет.

Проверки: 6 Python tests, release build, Android Lint, apksigner verify,
SHA256, API с реальными показателями, maintenance включение/выключение.
GitHub Actions: 41885522703. На физическом телефоне новая версия пока не проверена.

Установка: сохранить адреса, удалить предыдущую debug-версию, установить release.
Это переход на постоянную подпись: дальнейшие release-обновления совместимы по
ключу и package ID. Удаление стирает настройки. Включить уведомления и Tailscale,
ввести прежний URL мониторинга /status, запустить мониторинг.
