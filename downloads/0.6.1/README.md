# Pi Pocket Monitor 0.6.1

Добавлен адаптивный значок приложения: зелёный микрочип с линией пульса на тёмном фоне. Для уведомлений используется отдельный монохромный значок.

Устанавливается поверх release 0.5.x и 0.6.0 с сохранением настроек. Функции мониторинга не изменены.

Проверки: release build, Android Lint, контрольная сумма и прежний сертификат подписи. Отображение на физическом телефоне ещё не проверено.
