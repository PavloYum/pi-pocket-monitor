# 0.5.1 — Docker-сети в карточках

Каждая карточка сервиса показывает фактические Docker-сети и обязательные сети
из конфигурации. Зелёный индикатор — контейнер работает и сетевой endpoint
подключён. Красный — подключения нет. Обязательные сети отмечены отдельно.
Устаревшие снимки показываются серым, без утверждения о текущем подключении.
Это проверка подключения Docker endpoint, не тест маршрутизации между всеми узлами.

Серверная сводка обновлена; у n8n, Immich и камеры обязательные сети подтверждены.
Девять unit-тестов. CI выполняет release build, Android Lint и проверку подписи.
На физическом телефоне версия ещё не проверена.

Используется постоянный ключ 0.5.0: установка поверх release 0.5.0 с сохранением
настроек. При переходе со старых debug-версий нужна переустановка.
