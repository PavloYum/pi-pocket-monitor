# 0.4.0 — технические показатели и отдельные сервисы

- Шкалы CPU, RAM, заполнения дисков; температура, swap, uptime.
- Нагрузка за 1/5/15 минут, число ядер и сетевые счётчики.
- Отдельная карточка каждого ожидаемого сервиса: результат, метод и время проверки.
- HTTP / Docker healthcheck отличены от частичной проверки процесса или TCP.
- Остановленные/отсутствующие ожидаемые сервисы показываются недоступными.
- Устаревший снимок не отображается как актуальная доступность.

Проверено: четыре Python unit-теста, свежий API с 36 уникальными сервисами,
сборка APK и Android Lint (41248655344), SHA256 скачанного APK.
На физическом телефоне версия пока не проверена. Backend обновлён на Pi;
используется прежний настроенный VPN URL /status.

Debug APK: если Android отклонит обновление из-за подписи, сохраните настройки
перед переустановкой. Функциональные операции Telegram/MQTT/TURN не выполняются,
их частичные проверки не означают, что все функции приложения работают.
