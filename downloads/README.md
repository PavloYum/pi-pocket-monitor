# Версии приложения

Актуальная тестовая версия: [0.6.1](0.6.1/pi-pocket-monitor-0.6.1-release.apk).

В каждой папке находятся APK, контрольная сумма, сертификат и описание изменений.
Начиная с 0.5.0 используется постоянный release-ключ: обновления устанавливаются поверх приложения. Для перехода с прежних debug-сборок может потребоваться переустановка.

Сборка и Lint проверяются в GitHub Actions. Проверка интерфейса на телефоне выполняется отдельно.
