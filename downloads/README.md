# Версии приложения

Для каждого выпуска отдельная папка: `downloads/<версия>/`.
В ней должны находиться APK, SHA256SUMS и описание изменений.

Доступна [тестовая версия 0.5.1](0.5.1/pi-pocket-monitor-0.5.1-release.apk).
Сборка и Android Lint прошли; на телефоне пока не проверена.
Workflow Android APK собирает тестовую версию и предоставляет папку как GitHub
Actions artifact. После проверки APK на телефоне его можно добавить сюда
и в GitHub Releases. Публикация APK в Releases пока не автоматизирована.

Debug APK из разных CI-запусков может иметь разные ключи подписи и требовать
переустановки с потерей настроек. Для стабильных обновлений перед первым
production-релизом нужно создать постоянный release keystore, хранить вне Git
и настроить подписание. Публичные исходники не содержат ключей.

Начиная с 0.5.0 публикуются release APK с постоянным ключом. Предупреждение о разных debug-ключах выше относится к старым версиям.
