# Pi Pocket Monitor 0.6.0

- Раскрываемые блоки Immich, n8n, Booking, PiCall, BM, сайтов, туннелей и инфраструктуры.
- В каждом блоке — контейнеры, результаты проверок и схема общих Docker-сетей.
- Участники сети из других блоков показаны отдельно.
- Устаревшие данные явно помечены; общий доступ к сети не выдаётся за проверенный обмен трафиком.

Откройте «Обзор», прокрутите ниже графиков и нажмите «Контейнеры и связи».
Нужен настроенный источник устройства /status. Версию 0.6.0 можно установить поверх release 0.5.0/0.5.1 без удаления приложения.

Проверки: 9 серверных unit-тестов, release-сборка, Android Lint, SHA256 и прежний сертификат подписи. Проверка на физическом телефоне пока не выполнена.
